GITHUB LOGO SETUP
1. Upload logo.png to a public GitHub repository, e.g. images/logo.png.
2. Copy its public GitHub Pages URL (https://USERNAME.github.io/FBT-main/images/logo.png).
3. Replace index.html and script.js in your GitHub Pages repository.
4. Replace Code.gs in Google Apps Script and deploy a NEW version.
5. In Invoice App > Settings > Company Letterhead, paste the HTTPS Logo URL and click Save Settings.
6. On another device, click Reload Settings. Both devices and new PDFs use the same URL.

Use the public GitHub Pages image URL, not github.com/.../blob/...
PNG/JPG recommended, max 2 MB. config.js and style.css are unchanged.
Existing Drive logo is used as fallback until a GitHub URL is saved.
